Calendar demos

@lekoala/calendar — framework-agnostic Temporal calendar and resource scheduler Web Component.

Basic

Solo time grids, month and list over shared state. The small core demo: day, 3 days, week, month, list.

Resources

Resource time grids with acceptance fixtures (1×7, 2×3, 6×1, 6×3, 12×1), grouped headers and horizontal scroll.

Resources stress

Manual stress configurations (12×3, 6×7) to probe where the grid becomes UX-limited rather than slow.

Realtime

Incremental mutations (addEvent/updateEvent/removeEvent) standing in for WebSocket/SSE/polling messages.

Showcase

A generic application shell skinned with Actual CSS: rich event cards, creation/detail dialogs, context menu, local tools search and themes.

Dist smoke

Always loads the generated classic build (../dist/calendar.js); validates the distributed product over HTTP and file://.
